AgentGate

Is this AI agent accountable? Check the Concordium Agent Registry (CIS-8004) before you let it pay for or call your API.

Paid API for agents: GET https://agentgate.agentgate.workers.dev/v1/check-agent?id=… at 0.005 USDC per call on Base via x402 (unpaid calls get HTTP 402 with the terms). Listed in the x402 Bazaar (PayAI).

Examples:

Gate your x402 API in 3 lines

import { agentGate } from 'concordium-agentgate';
// before your x402 paymentMiddleware: unverified agents get 403 and are never asked to pay
app.get('/paid', agentGate({ network: 'testnet' }), paymentMiddleware(/* ... */), handler);

Agents send their badge in the X-Agent-Badge header. AgentGate checks the registry record is Active and the Agent Card's SHA-256 matches the on-chain metadata_hash. MCP clients can call the check_agent tool (npx -y -p concordium-agentgate agentgate-mcp). Integration guide · Source.

Lookups go straight from your browser to Concordium's public endpoints (agent-registry-mcp.concordium.com: badge-check REST for mainnet, hosted MCP for testnet/devnet). No data is sent to AgentGate. Open source (MIT). Independent project, not affiliated with Concordium.
